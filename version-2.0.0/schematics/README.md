# Diagrama de Conexiones - Invernadero ESP32

## Pines utilizados

| Periférico | Pin ESP32 | Tipo |
|---|---|---|
| LM35 (temperatura) | GPIO 34 | ADC |
| LDR (luz) | GPIO 32 | ADC |
| Ventilador (Motor DC) | GPIO 18 | PWM |
| LED de potencia | GPIO 19 | PWM |
| GND común | GND | - |
| VCC 3.3V | 3V3 | - |
